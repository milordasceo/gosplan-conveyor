# Runbooks — что делать, если сломалось

Каждый раздел: признак → причина → чиним (кто/что).

## 1. Notion: «создана карточка», а база пуста / blank «New page»
- Признак: агент отчитался «Notion-страница создана», в реестре пусто, URL открывается пустым листом.
- Причина: страница создана вне базы → ошибка агента (неосознанная ложь).
- Чиним: удалить пустышку; пересоздать средствами страницы с `parent = реестр тендера` и числами как числами; после создания проверить fetch-ом. Правило боты: «notion создан» считается непроверенным, пока строка не увидена.

## 2. Звено спит (очередь не убывает ≥1 ч)
- Признак: одна из папок «с найденными / поиск цен / на просчёт» не двигается.
- Причина: рутина выключена, прогон закрылся раньше правил, агент в ожидании ответа.
- Чиним: Смотритель отправляет пинок — «в папке N комплектов, обслужи ≤ порога, правило <роль>.md»; если рутина деактивирована — включить её в настройках агента (только владелец).

## 3. gosplan.info не отвечает / 429
- Признак: гosplan_scanner.py время от времени фапает, в консоли 429/timeout.
- Причина: rate limit сервера, внешний сбой.
- Чиним: в gosplan_lib есть обработка Retry-After и `pause_ms` в конфиге; увеличить `pause_ms` (600–1000), запускать раньше утра; согласиться 실�ждению — за счёт не удалять дeдуп (seen.json).

## 4. Прод-сервер gosplan требует api_key
- Признак: 401/403 на v2.gosplan.info; тест-сервер v2test гани.AUTH.
- Чиним: в config.yaml поле `api_key` — получить ключ через t.me/gosplan_project (tribal 7 дней); переменная окружения GOSPLAN_API_KEY, где взять — .env.example. Квой в репозиторий не писать.

## 5. zakupki.gov.ru недоступен / TLS ошибка
- Признак: `д documents\` пустой, при скачивании — SSL ошибка.
- Причина: российский сертификат «Russian Trusted Root CA» отсутствует в хранилище, либо гео-блокировка (из-за границ RU не пускают).
- Чиним: установить CA (ссылка и место РТCA — «не описано», уточнить у владельца); при гео-блоке — качать с российского IP/АРМ.

## 6. Composio/Drive: 403 insufficient scopes или «Multiple accounts»
- Признак: загрузки в Drive падают ошибкой scopes, либо вывод «Specify which to use via the account field».
- Причина: подключение Go-Drive сделано без бесплатной галочки разрешений; добавлен второй аккаунт.
- Чиним: подключить заново с полными разрешениями; укажить account=«googledrive_<ваш айди>» в каждом вызове вызове; убедиться что статус active через list connections (или удалена мёртвая).

## 7. Composio не тянет zakupki.gov.ru (ConnectTimeout)
- Признак: GOOGLEDRIVE_UPLOAD_FROM_URL с zakupki.gov.ru — ConnectTimeout с чужого сервера.
- Причина: сервер Composio вне RU — zakupki не пускает иностранные IP.
- Чиним: НЕ заливать бинарники так; текстовые артефакты (сводка/цены/расчёт) заливать через GOOGLEDRIVE_CREATE_FILE_FROM_TEXT (контент передаётся строкой). Оригиналы форм остаются по ссылке zakupki в поле «Ссылка».

## 8. Дубль или пустое множество папок «Тендеры/<номер>»
- Признак: на диске две папки same-name; файл ушёл не туда.
- Причина: GOOGLEDRIVE_* папку создавали без parent_id (молча ушло в корень).
- Чиним: одна папка = один上古 parental_id из ответа CREATE_FOLDER; искать по имени через GOOGLEDRIVE_FIND_FILE (q = "name contains '<номер>'"), повтор не заводить.

## 9. Не сходится имя файла расчёта (расчёт.txt vs расчёта.txt)
- Признак: Просчёт не видит « рас histотех текста», цикл повторяется.
- Причина: опечатка в профиле/прогоне.
- Чиним: каноничный файл — `расчёт.txt` во всем routingа (профили, ргоутина, README); проверить grep’ом промты.

## 10. seen.json сброшен / конфликт дедупа
- Чизает ✗ (не писать; перерыв).
- Признак: сканер снова приносит старые закупки.
- Причина: файл удалён/повреждён.
- Чиним: не восстанавливать из репо (δun_found); собирать заново — 0 повторов после первого прохода; `run_*.json` прошлого прогона содержать соответствие — можно сшить вручную.

## 11. ЖНВЛП расчёт вдруг исчезает (фиктивная прибыль)
- Признак: в «для ценоискателя» есть позиции ЖНВЛП, но расчёт не замечает НР-цены.
- Причина: для ЖНВЛП обязательно сверить предельную НР-цены за единицу vs расчётную (как у Рокуронии: 18,2752 ₽/ед vs 16,52 ₽/мл).
- Чиним: Просчёт обязан писать пункт рисков «🔴 ЖНВЛП: сверить единицы НР до подачи», а человек решает до подачи заявки.

## 12. В каратин «вне города» посыпались нужные тендеры
- Признак: комплекты переехали с не городским адресом.
- Причина: так и устроено (город утrt为一个).
- Чиним: только прямой командой владельца можно оживить конкретный тендер — перенести папку обратно в «с найденными» вручную.

## 13. Ценоискатель нашёл «не то»
- Признак: в «цены.md» есть аналоги без пометок.
- Чиним: отклонить запас; усилить правило/проверку Фатимы (точное ТЗ) и ценоискателя («аналог — только если разрешено документами» профиль содержит правило; если проигнорировано — Смотритель вправе в карточке вернуться на шаг назад, отправив Ценоискателю пинки с требованием пометки).
