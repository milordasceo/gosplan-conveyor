# gosplan-conveyor

Переносимый пакет тендерной команды (собран из работающего OpenBot-приложения 28.10.2026).

## Что это

Автоматический конвейер госзакупок: сканирует публикации (gosplan.info API по 44-ФЗ/223-ФЗ), отбирает Новосибирск 30 000–150 000 ₽, разбирает документы, ищет источники дешевле НМЦК, считает маржу и кладёт выгодные сделки в Notion-CRM с файлами в Google Диске.

## Команда (роли)

1. **Кузнец** — поддерживает скрипты в `scripts/` (сканер, фильтр города, извлечение предмета).
2. **Фатима** — разбирает новые комплекты документов, готовит файлы для следующих звеньев.
3. **Ценоискатель** — ищет в интернете источники дешевле НМЦК (только Новосибирск и НСО).
4. **Просчёт** — считает маржу (логистика, накладные, УСН), порог ≥ 10 000 ₽, создаёт карточку в Notion + папку в Google Диске.
5. **Смотритель** — надзиратель: пинает уснувшие звенья, чинит карточки CRM, даёт владельцу сводку дважды в день (13:00 и 19:00) и срочно — по стопору.

Правило канала: звенья 1–4 владельцу не пишут никогда; всё идёт Смотрителю.

## С чего начать

1. Прочитай `docs/ARCHITECTURE.md` и `docs/WORKFLOW.md` — карту команды и маршрут тендера.
2. Скопируй `scripts/` на машину-воркер (Linux с шеллом и браузером), поставь зависимости (см. заголовки файлов).
3. Заполни `.env.example` → `.env` (gosplan api_key при необходимости).
4. Заведи аккаунты по списку внешних сервисов из `docs/INVENTORY.md` (gosplan.info, Notion, Google Drive, Composio или прямой аналог).
5. Вставь промты из `prompts/` в новых агентов (5 ролей — как есть).
6. Настрой рутины по `docs/INVENTORY.md` (раздел «Расписания»).
7. Прогони `docs/WALKTHROUGH.md` на одном реальном тендере — проверь, что цепочка даёт карточку.

## Ограничения

- В репозитории нет ключей и токенов: только имена переменных и где их взять (`.env.example`).
- Личные данные заказчиков отсутствуют: только структура и правила.
- Чего не подтвердили — «не описано» в `docs/MIGRATION.md` (раздел «Пробелы»).
